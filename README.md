# Вселенная Ozon671Games — прототип

Статический многостраничный прототип без внешних зависимостей.

## Запуск

Откройте `index.html` напрямую или запустите локальный сервер:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Что реализовано

- адаптивная главная, каталог, произведение, AI-фильмы, магазин, кабинет;
- мобильная и desktop-навигация;
- каталог с поиском, фильтром жанра, сеткой/списком;
- мини-аудиоплеер, скорость, localStorage прогресса;
- корзина в localStorage и демо-checkout без списания;
- карта связей;
- маркировка AI-контента;
- WCAG-friendly focus, семантика, reduced motion;
- schema.org Book/Product заготовки;
- без сторонних изображений: используются безопасные визуальные заглушки.

## Для production

Нужно подключить CMS/backend, реальный audio/video player, авторизацию и синхронизацию, CDEK API, платёжный провайдер, проверенные права на медиа, реальные метаданные и оптимизированные AVIF/WebP assets.
